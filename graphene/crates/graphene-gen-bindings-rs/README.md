# graphene-gen-bindings-rs

`graphene-gen-bindings-rs` generates Rust data-model crates from the generated
open-graphene OpenRPC specs.

It is intentionally scoped to **models only**:

- JSON-serializable schema structs generated with `typify`
- custom Rust enums for Graphene `static_variant` schemas
- operation metadata constants generated from `x-graphene-operation`

It does **not** generate transport, websocket connection management, transaction
builder ergonomics, signing, fee calculation, or subscription runtime code. Those
layers should be designed manually on top of the generated models.

## Inputs

The generator reads chain bundle manifests produced by `graphene-gen-spec`:

```text
graphene/specs/acta/open-graphene.json
graphene/specs/swaplock/open-graphene.json
```

Each manifest references one or more OpenRPC surface specs, such as:

```text
graphene/specs/acta/api.database.json
graphene/specs/acta/api.network-broadcast.json
```

The generator merges `components.schemas` across the chain surfaces before
emitting one Rust binding crate per chain.

## Outputs

Generated files are written into the `graphene-rs` workspace:

```text
graphene-rs/crates/graphene-bindings-acta/src/generated/types.rs
graphene-rs/crates/graphene-bindings-acta/src/generated/variants.rs
graphene-rs/crates/graphene-bindings-acta/src/generated/metadata.rs

graphene-rs/crates/graphene-bindings-swaplock/src/generated/types.rs
graphene-rs/crates/graphene-bindings-swaplock/src/generated/variants.rs
graphene-rs/crates/graphene-bindings-swaplock/src/generated/metadata.rs
```

The binding crate root re-exports generated symbols:

```rust
pub use generated::*;
```

## Commands

Run from the repository root.

Generate both chain binding crates:

```sh
cargo run -p graphene-gen-bindings-rs --bin graphene-gen-bindings-rs -- --chain all
```

Generate one chain:

```sh
cargo run -p graphene-gen-bindings-rs --bin graphene-gen-bindings-rs -- --chain acta
cargo run -p graphene-gen-bindings-rs --bin graphene-gen-bindings-rs -- --chain swaplock
```

Generate from a custom manifest into a custom crate directory:

```sh
cargo run -p graphene-gen-bindings-rs --bin graphene-gen-bindings-rs -- \
  --manifest graphene/specs/acta/open-graphene.json \
  graphene-rs/crates/graphene-bindings-acta
```

Verify the generated crates:

```sh
cargo test --manifest-path graphene-rs/Cargo.toml
```

## Generated module responsibilities

### `types.rs`

Generated by `typify` from merged JSON Schema definitions. It contains Rust
structs/enums/wrappers for regular `components.schemas` entries.

### `variants.rs`

Generated manually for Graphene `static_variant` schemas because their JSON wire
shape is `[index, payload]`. The emitted enums implement custom
`serde::Serialize` and `serde::Deserialize` to preserve that representation.

Example:

```json
[0, { "fee": { "amount": 0, "asset_id": "1.3.0" }, "from": "1.2.100", "to": "1.2.101", "amount": { "amount": 42, "asset_id": "1.3.0" }, "memo": null, "extensions": [] }]
```

becomes:

```rust
Operation::Transfer(TransferOperation { /* ... */ })
```

### `metadata.rs`

Generated from `x-graphene-operation`. It exposes operation IDs and names without
requiring SDK code to parse JSON specs at runtime:

```rust
pub struct OperationMetadata {
    pub id: u16,
    pub name: &'static str,
    pub cpp_type: &'static str,
    pub rust_type: &'static str,
    pub schema: &'static str,
}

pub const OPERATIONS: &[OperationMetadata] = &[
    OperationMetadata {
        id: 0,
        name: "transfer",
        cpp_type: "transfer_operation",
        rust_type: "TransferOperation",
        schema: "#/components/schemas/transfer_operation",
    },
];
```

## Helper binary

`openrpc-typify-rs` is a low-level helper that can convert either a JSON Schema
document or an OpenRPC document with `components.schemas` into Rust types:

```sh
cargo run -p graphene-gen-bindings-rs --bin openrpc-typify-rs -- \
  --schema graphene/specs/acta/api.database.json \
  --out /tmp/types.rs
```

Normal regeneration should use `graphene-gen-bindings-rs`, not this helper.

## Relationship to `graphene-v2`

This crate borrows the proven Rust generation shape from
`graphene-v2/graphene/crates/graphene-gen-rust`:

- `typify` for regular JSON Schema models
- custom Rust enums for `static_variant`
- generated metadata for downstream SDK layers

The v3 version targets the new open-graphene bundle layout and writes into the
new `graphene-rs/crates/graphene-bindings-*` crates.
